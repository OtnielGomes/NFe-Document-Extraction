# Evaluation results

Generated by `scripts/run_eval.py`. Do not edit by hand.

Model snapshot: `gpt-4.1-mini-2025-04-14 (single-call baseline, cheap vision, text layer + text model); gpt-4.1-2025-04-14 (strong vision)`. Pricing table date: 2026-10-03.

Description similarity is the normalized Levenshtein ratio after casefold, accent removal, and whitespace collapse. A description is correct at >= 0.95.

Field accuracy is an exact match after normalization. Product codes and descriptions are compared after casefold, accent removal, and whitespace collapse. Each missing item and each spurious item counts as one error. Planted-error documents are excluded from field accuracy and are scored by detection rate. Description similarity and the perfect-invoice rate still include them, because ground truth is the printed value.

Latency p95 uses linear interpolation between closest ranks. Errors caught by the validator counts clean documents with at least one failing validation rule on the first reading. Errors fixed by repair counts clean documents accepted after the single Repair attempt. Errors reaching Human review counts clean documents whose outcome is Human review. The single-call baseline does not repair.

Photo renditions are not applicable to the text-layer approach. It reads the PDF text layer and skips Simulated photos and Phone photos.

Compare the digital PDF row with the simulated photo row of the same Extraction approach to see the accuracy drop from PDF to photo.
